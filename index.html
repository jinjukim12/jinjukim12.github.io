Smart Logistics Delay Control Agent Framework

기존의 배송 지연 사후 조치 방식을 넘어, 1개의 LLM(Gemini)과 2개의 SLM(MiniLM + TinyLlama LoRA) 및 LangGraph 오케스트레이션을 결합한 선제적 물류 제어 시스템입니다.

  • 기존 한계 대응: 단순 예측 모델의 의사결정 부족 및 LLM 단독 사용 시의 낮은 신뢰성 문제 해결
  • 핵심 기능: 배송 지연 위험 예측을 수행하는 동시에, 예측치를 바탕으로 최적의 제어 행동 추천
  • 의사결정 지원: 고위험 주문을 실시간으로 식별하여 물류 담당자의 실질적 행동 및 비용 기반 최적화 프로세스 연결

• Temperature: 값이 낮을수록 더 안정적이고 예측 가능한 문장이 생성되며, 높을수록 다양하고 창의적인 표현이 증가한다.
• Top-k: 고려하는 후보 단어의 개수를 제한하는 방식으로, 값이 작을수록 보수적인 출력이 나오고 클수록 다양한 표현이 가능해진다.
• Top-p: 누적 확률을 기준으로 후보를 선택하여, 값이 낮으면 일관성이 높고 값이 높으면 더 다양한 텍스트가 생성된다.
